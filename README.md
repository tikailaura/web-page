# Movie Rental Website

## Description
This project is a simple Movie Rental website created using HTML and CSS. It was developed as a school assignment to practice creating multi-page websites, page layouts, and navigation.

## Features
- Login and Register page
- Home page displaying available movies
- Your Movies page
- Profile page
- Responsive and clean layout
- Navigation between pages
